
# ✨ StyleAura – Premium Fashion E-Commerce Website

A modern, responsive and stylish fashion e-commerce frontend inspired by popular online shopping platforms like Myntra.

StyleAura provides a clean shopping experience with product discovery, category filtering, wishlist management, shopping cart and more.

## 🌐 Project Overview

StyleAura is a frontend web development project built using HTML5, CSS3 and JavaScript.

The project focuses on modern UI design, responsive layouts and interactive shopping functionalities.

## 🚀 Features

- Premium Fashion Homepage
- Modern Navigation Bar
- Responsive Design
- Product Search Functionality
- Category-Based Filtering
- Product Sorting
- Product Quick View
- Add to Shopping Bag
- Increase / Decrease Product Quantity
- Remove Products from Cart
- Automatic Cart Total Calculation
- Wishlist Management
- Local Storage Integration
- Newsletter Subscription UI
- Mobile-Friendly Layout
- Interactive Notifications

```bash

```

- Explore the StyleAura website.

## 🛍️ Shopping Features

### Product Management
- Browse fashion products.
- Search products by name and brand.
- Filter products by category.
- Sort products according to price and ratings.

### Shopping Cart
- Add products to your bag.
- Increase or decrease quantities.
- Remove products.
- Calculate total shopping amount automatically.

### Wishlist
- Save favourite products.
- Remove products from wishlist.
- View saved products separately.

### Data Persistence
Cart and wishlist information is stored using browser Local Storage.
